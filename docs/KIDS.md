# Детская мини-игра: своя головоломка у каждой страны

Решение владельца 02.11. Раз за жизнь, в детстве (7–10 лет), ребёнок выбирает задание: **Тело** (здоровье и сила),
**Ум** (ум и грамота) или **Люди** (обаяние и положение), - и решает головоломку своей страны. Звёзды (0–3) решают,
сколько прибавится (`REWARD` в `src/kids/types.ts`). Макеты - `tools/mockups/kids.html`, стенд для игры - `tools/kids-play.html`
(`npx vite --port 5174`, затем `http://localhost:5174/tools/kids-play.html?game=canals&level=3`).

## Устройство

- `src/kids/types.ts` - `PuzzleLogic<S, M>` (чистая логика) и `KidsPuzzle` (логика + доска + тексты).
- `src/kids/rng.ts` - `makeRng`, `randInt`, `pickOne`, `shuffle`, `bfs` (кратчайшее решение и подсказка).
- `src/kids/KidsGame.tsx` - общий экран: выбор задания → доска → звёзды. Держит состояние, считает ходы, делает
  подсказку (`logic.hint` → подсветка хода на доске через `hinted`), «Сначала» (вернуть `level.start`), «Бросить».
- `src/kids/index.ts` - собирает все `src/kids/*Board.tsx` сам (`import.meta.glob`): правок реестра не нужно.
- Образец - **Каналы** (Египет): `src/kids/canals.ts` + `src/kids/CanalsBoard.tsx`.
- Тест - `tests/kids.test.ts`: на каждом уровне 1–5, каждом задании и 12 зёрнах уровень не решён в начале, эталон
  (`solution`) решает и его длина = `par`, только подсказками можно дойти до решения, генерация < 1,5 с.
  Одна игра: `KIDS_ONLY=canals npx vitest run tests/kids.test.ts`.

## Правила для каждой игры

1. Логика в `src/kids/<id>.ts`, экспорт `<id>: PuzzleLogic<S, M>`. Состояние - простой объект (JSON), `apply` не меняет
   старое состояние (возвращает новое) и возвращает `null` для недопустимого хода. Ход `M` - простое значение (число,
   строка или маленький объект); доска сравнивает подсказанный ход с элементами по значению (`JSON.stringify`).
2. `generate(difficulty 1..5, rng, task)` - детерминирован от rng. Уровень 1 решается ребёнком за 1–2 минуты, 5 - заметно
   сложнее, но на телефоне не больше 5 минут. Задание (`task`) меняет цель или тему (что взвешиваем, куда ведём воду);
   если игре всё равно - хотя бы разные подписи. `par` = длина `solution` (оптимум, если считается поиском;
   иначе длина известного решения). Никаких `Math.random` - только `rng`.
3. `hint(s, level)` - следующий хороший ход из *текущего* состояния (не только из начала): поиск (`bfs`) или правка
   первой ошибки. Подсказки подряд обязаны доводить до решения (это проверяет тест). Если игрок сделал что-то
   неправильное (например, поставил не тот цвет) - подсказка должна это исправлять.
4. Доска в `src/kids/<Имя>Board.tsx`: компонент `(p: BoardProps<S, M>) => JSX`, рисует SVG (`<svg class="kb-svg" viewBox>`),
   ширина - по контейнеру (до ~460 px), клетки на телефоне не меньше ~40 px. Ввод - тапы (без перетаскивания:
   «выбрал → поставил»), локальное состояние выбора - `useState` в доске. Подсвеченный ход - класс `kb-hint`
   (мигает). `done` - доска только показывает. Кнопки под полем (палитра, стрелки) - классы `kb-palette`, `kb-swatch`,
   `kb-arrows` из `src/kids/kids.css`. Цвета - тёплые, как в макете; на тёмном фоне контрастно.
5. Экспорт `<id>Puzzle: KidsPuzzle` в том же файле доски: `id`, `era`, `region`, `place` (ScenePlace из `src/engine/types.ts`),
   `logic`, `Board`, `text: { ru, en, tr }` - `title`, `story` (1–2 предложения, к ребёнку на «ты»), `rule` (одно
   предложение, как играть), `tasks` (Тело, Ум, Люди - что за задание). Тексты - без длинного тире «—»: между словами
   дефис «-». Русский - без мужского рода в обращении к ребёнку (герой может быть девочкой): «ты решил» нельзя,
   «получилось» - можно. Подписи на самой доске - тоже на трёх языках (через `lang`).
6. Стиль кода проекта: без точек с запятой, одинарные кавычки, комментарии по-русски. **Prettier не запускать.**
   Проверка: `npx tsc --noEmit -p .` и `KIDS_ONLY=<id> npx vitest run tests/kids.test.ts` (поднять `KIDS_SEEDS=40` для
   финального прогона).
