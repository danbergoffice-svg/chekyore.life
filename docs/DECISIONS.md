# Решения по проекту

Ответы на открытые вопросы ТЗ (`docs/game_spec.json`, раздел 17) и другие решения для бета-версии.
Дата: 2026-10-24.

## Продукт

| Вопрос | Решение |
|---|---|
| Название (Q1) | «Тысячи жизней» / **Thousands of Lives** |
| Домен | https://thousands.life (GitHub Pages) |
| Оплата (Q2) | В бете всё бесплатно, платёжные функции не подключаем |
| Площадка (Q4) | Только свой сайт. Яндекс Игры и Telegram — ближе к релизу; код пишется так, чтобы их было легко добавить |
| Языки (Q5) | Русский + английский с самого начала |
| Эпохи (Q8) | Бета на одной эпохе: **E03 Классическая античность**, остальные добавляются по одной |
| Регионы E03 | Рим, Афины, Египет |

## Контент и графика

| Вопрос | Решение |
|---|---|
| Исторические тексты (Q6) | Пишет Claude, в бете без внешней проверки. В игре пометка «бета, тексты не выверены», правки по отзывам. Историк — к релизу |
| Визуальный стиль (Q3) | Интерфейс — тёплая бумага и сепия. Иллюстрации — пиксельные сцены-панорамы 16:5 по образцам владельца (2026-10-25): небо полосами, силуэт места, земля с узором, маленькие человечки и предметы |
| Иллюстрации | Каждое событие описано сценой (`scene`: место, время суток, люди, предметы). Игра рисует её пикселями (`src/pixel/scene.ts`), из того же описания собираются промпты для настоящих картинок: `npm run prompts` → `docs/image_prompts.json` |
| ИИ в рантайме (Q9) | В бете нет: жизнеописание собирается из шаблонов |

## Итоги жизни (ТЗ 1.1, раздел 17a)

| Вопрос | Решение |
|---|---|
| Названия 16 архетипов (Q10) | Рабочие из ТЗ, лежат в файлах текстов `archetype.XXXX` — меняются без правок кода |
| Общий мемориал (Q10) | Не в бете: нужен сервер и модерация. Поделиться можно картинкой-карточкой и текстом |
| Веса «Узора жизни» | `src/content/pattern_weights.json` |

## Техника

| Вопрос | Решение |
|---|---|
| Сервер и аккаунты (Q7) | Нет. Сохранения в браузере (IndexedDB) + экспорт/импорт файлом |
| Аналитика | Яндекс Метрика, счётчик 113771699 (`src/analytics.ts`): посещения, вебвизор, карта кликов и игровые цели через `track()`. Только в собранной версии сайта |
| Стек | TypeScript, Vite, PWA; весь контент в JSON |
