# Публикация на CrazyGames

## Сборка

```bash
npm install
npm run build:crazygames      # → dist-crazygames/ и crazygames.zip
```

`crazygames.zip` загружается в кабинете разработчика CrazyGames как HTML5-игра (`index.html` в корне архива).
Упаковщик `tools/pack-crazygames.mjs` сам проверяет, что:

- в сборке нет внешних адресов, кроме SDK CrazyGames (`https://sdk.crazygames.com/crazygames-sdk-v3.js`);
- нет упоминаний сайта, абсолютных путей `/…`, не превышены лимиты (≤ 1500 файлов, ≤ 20 МБ).

Если проверка не прошла — архив не создаётся, в консоли список проблем.

## Чем сборка отличается от сайта

Код платформы — `src/platform/crazygames.ts`, выбирается переменной `VITE_PLATFORM=crazygames` при сборке
(код сайта — Метрика, свой приёмник — в архив не попадает).

| На сайте | На CrazyGames |
| --- | --- |
| Яндекс Метрика и свой приёмник событий | Только сигналы SDK CrazyGames, своей статистики нет |
| Шрифт с внешнего сервера | Шрифты лежат в сборке: Alegreya (`@fontsource-variable/alegreya`) и «Летопись» (`src/fonts`); внешних запросов нет ни на сайте, ни на портале |
| Превью для соцсетей, манифест, офлайн-кэш | Убраны |
| «Поделиться»: системное меню, X, Threads, ссылка на thousands.life | Картинка карточки и «Скопировать текст» со ссылкой-приглашением на страницу игры на CrazyGames |
| Форма отзывов | Скрыта (отзывы — в комментариях на странице игры) |
| Рекламы нет | Полноэкранная реклама SDK (`midgame`) после экранов-глав в 16, 30, 45, 60 лет; частоту ограничивает CrazyGames |
| Барабан: 3 вращения на жизнь (рывок + 2 перекрутки), потом «Судьба решена» | 3 вращения бесплатно, дальше кнопка «▶ Spin again — watch an ad»: реклама за награду (`rewarded`), досмотрел — ещё вращение, и так каждый раз; не досмотрел или рекламы нет — результат остаётся, всплывает «No ad available right now» |
| Сохранения в IndexedDB | IndexedDB + копия в модуле `data` SDK: у вошедших в аккаунт — на всех устройствах |
| Язык по браузеру (русский у русскоязычных) | Всегда английский при первом запуске; русский — переключателем EN/RU или в настройках |
| Музыка | Та же; дополнительно молчит, если в CrazyGames включено «без звука» (`settings.muteAudio`), и во время рекламы |

## Какие сигналы получает CrazyGames

| Когда | Вызов SDK |
| --- | --- |
| Запуск, до главного меню | `loadingStart` → `loadingStop` |
| Рывок рычага лотереи рождения в меню; нажата «Start life» и идёт жизнь героя (время идёт или открыто решение события) | `gameplayStart` |
| «Spin again — watch an ad» | `requestAd('rewarded')`; на время рекламы `gameplayStop` и тишина, после — `gameplayStart` |
| Экран знакомства с семьёй, пауза без решения, экран-глава, реклама, смерть, меню, настройки, мемориал, итоги | `gameplayStop` |
| Каждая новая жизнь или «Continue» из меню | новый `gameplayStart` |
| Герой дожил до 60+, игрок продолжил род наследником | `happytime` |
| «Скопировать текст» в итогах | `inviteLink` |

Каждый сигнал загрузки, игры и happytime пишется в консоль браузера строкой `[CrazyGames SDK] gameplayStart` и т.п. —
в QA Tool так видно, что и когда ушло.

Своих событий (как `life_start`, `choice_made` на сайте) SDK CrazyGames не принимает — у портала нет модуля
произвольной аналитики. Запуски, время в игре, долю дошедших до игры, удержание и доход от рекламы
CrazyGames считает сам по этим сигналам и показывает в кабинете разработчика. Наружу данные не уходят.

## При публикации в кабинете

- Включить сохранение прогресса (Save progress / Data module) — иначе модуль `data` отключён и сохранения
  будут только в браузере игрока.
- Проверить игру в их QA Tool: должны быть видны события загрузки, геймплея, реклама после главы и реклама за награду
  после трёх вращений барабана.
- Без сети к SDK проверка рекламы за перекрутку — `node tools/qa/cg-respin.cjs` (имитация SDK; нужен
  `npx vite preview --outDir dist-crazygames --port 4174`).
- Локально SDK можно проверить так: `npx vite preview --outDir dist-crazygames` и открыть
  `http://localhost:4173/?useLocalSdk=true` (вне CrazyGames и localhost SDK отключается, игра работает без него).
