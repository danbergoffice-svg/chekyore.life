# Библиотека стилей

Nov 3, 2026 · стили рисования кодом для сцен и людей по странам. Источник - библиотека Lemo-Opuscar
(github.com/lemomo-ai/lemo-opuscar, LemoLab): 66 стилей, каждый - описание («style prompt») и демо, нарисованное
кодом. Нам подходят 10, они лежат в `opuscar/` без изменений.

**Лицензия.** Тексты и код - MIT (`opuscar/LICENSE`, уведомление сохранять при копировании). Демо-ролики и кадры
из них - CC BY 4.0: если берём картинку оттуда, указываем LemoLab со ссылкой и что изменили. Описания стилей
написаны для фильмов (камера, звук, титры): для игры берём разделы 1–3 (суть, материалы, цвет) и 9 (ловушки).

## Что к какой стране

Наши 16 стилей - из `docs/TZ_graphics.md` (раздел G5).

| Наш стиль (страны) | Стиль библиотеки | Что взять |
|---|---|---|
| Готический (Европа) | `impasto` - масло мастихином | мазки-плоскости по эскизу, свет по рельефу краски, тёплый свет против холодной тени |
| Готический, после ~1450 | `woodcut`, `engraving` | гравюра: штриховка по форме, свет - там, где вырезано |
| Византийский, готический (храмы) | `stained-glass` | витраж: свинцовые переплёты, свет сквозь стекло, гризайль |
| Китайский | `ink-wash` | тушь сеи: пустая бумага - пространство, один мазок - гора |
| Японский | `ukiyoe`, `ink-wash` | гравюра на дереве: плоские цвета, резной контур, небо-бокаси, текстура бумаги |
| Исламский (Османы), индийский | `shadow-puppet` | театр теней: Карагёз у турок, тхолу боммалата в Индии - резные силуэты на просвет |
| Китайский (народный) | `papercut-red` | бумажная вырезка: вырез - это рисунок |
| Любой, книжная миниатюра | `watercolor` | прозрачные мазки, сухая кисть, тёплая бумага |
| Все сцены | `hd-2d` | приём всей сцены: плоские спрайты в освещённой диораме, тени от огней, дымка, тилт-шифт |

**Чего в библиотеке нет** и рисуем сами: икона (Русь), мозаика (Византия), краснофигурная вазопись (Греция),
роспись гробниц (Египет), кодексы (ацтеки), майяская роспись, эфиопская церковная роспись, боголан (Мали).

## Порядок

1. Европа: перенести рисовальщик `impasto` (WebGL: эскиз → мазки мастихином → свет) на детальный фон улицы
   (`src/pixel/hd.ts` даёт эскиз, рисовальщик перерисовывает его мазками один раз, результат кэшируется).
2. Если пойдёт - тот же приём для людей (мазки с постоянным зерном, чтобы краска не «кипела» при анимации).
3. Затем Китай (`ink-wash`) и Япония (`ukiyoe`), Османы (`shadow-puppet`).
