# Тысячи жизней (Thousands of Lives)

Браузерная игра-симулятор одной жизни в случайной исторической эпохе. Сайт: https://thousands.life

ТЗ: [docs/game_spec.json](docs/game_spec.json), принятые решения: [docs/DECISIONS.md](docs/DECISIONS.md).

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты движка и контента, симуляция тысяч жизней
npm run build    # сборка в dist/
```

## Устройство

- `src/engine/` — движок без исторических данных: генерация героя, годовой цикл, события, смертность, наследование. Случайность воспроизводима по seed.
- `src/content/<эпоха>/` — всё содержание эпохи: `era.json` (регионы, сословия, профессии, фокусы года, таблица смертности), `events.json` (события), `ru.json` / `en.json` (тексты).
- `src/i18n/` — тексты интерфейса и форматирование (`{g:он|она}` — род по полу героя, `{p=n:год|года|лет}` — числа).
- `src/ui/` — экраны на Preact.
- `tests/` — проверка целостности контента и симуляция: средняя продолжительность жизни должна совпадать с исторической.

Новая эпоха: папка в `src/content/`, строка в `src/content/index.ts` и тексты в `src/i18n/index.ts`.

## Публикация

Каждый push в `main` проходит тесты, собирается и публикуется на GitHub Pages
(`.github/workflows/deploy.yml`). Домен задаётся в настройках Pages и файлом `public/CNAME`.
