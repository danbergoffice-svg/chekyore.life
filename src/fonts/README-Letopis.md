# «Летопись» (Thousands Letopis) - версия 0.2

Заголовочный шрифт игры «Тысячи жизней»: глифическая антиква широкого пера (30°)
с клиновидными засечками. Прописные + капитель (строчные буквы набираются капителью).

## Что нового по сравнению с 0.1
- **Новый движок пера.** Огибающая пера строится точно, кривыми Безье, без булевых
  ломаных: контуры гладкие, точек в 5–10 раз меньше.
- **Вариативная ось `wght` 300–700** (Light → Bold) и 5 статических начертаний.
- **Заметные клиновидные засечки** и шпоры на концах горизонталей (E, T, L, Z, Г…).
- **Обычные Л и Д**; древние формы Λ-образных Л/Д - через `ss01`.
- **Диакритика через якоря**: отдельные, более плоские знаки для прописных (`.case`),
  комбинируемые знаки U+0300…0328 позиционируются через `mark`, после прописных
  сами переключаются на `.case` (`ccmp`).
- **Символы для интерфейса**: `[ ] { } \ | _ + − = × ÷ ± < > ^ ~ * # % & @ • ‹ › → ←`,
  `° ª º © ® ™`, валюты `$ € £ ¥ ₽ ₴ ₺`, тонкие/цифровые пробелы.
- **OpenType**: `kern` (≈3550 пар в 98×83 классах: автокернинг по общему просвету пары, для пунктуации - по глубине «вылета» буквы),
  `mark`, `ccmp`, `locl` (турецкий/азербайджанский/крымскотатарский i → İ),
  `case`, `tnum`/`pnum`, `c2sc`, `cpsp`, `ss01`.
- Хинтинг статики (ttfautohint), корректные вертикальные метрики, все файлы проходят OTS.

## Языки
Русский, украинский, английский, испанский, португальский, немецкий (ẞ/ß), французский,
итальянский, турецкий, польский; также чешский, румынский, белорусский Ў.

## Файлы (`dist/`)
| Файл | Для чего |
|---|---|
| `variable/ThousandsLetopis[wght].woff2` (≈54 КБ) | веб/игра, все веса в одном файле |
| `woff2/ThousandsLetopis-*.woff2` (≈26 КБ) | веб, отдельные веса |
| `ttf/ThousandsLetopis-*.ttf` | движки (Unity TMP, Unreal, Godot), дизайн; без перекрытий, с хинтингом |
| `variable/ThousandsLetopis[wght].ttf` | дизайн и движки с поддержкой VF |

> Для генераторов SDF/MSDF (TextMeshPro, Godot MSDF) берите **статические TTF**: в
> вариативном файле контуры перекрываются, как и положено VF, а MSDF этого не любит.

## Подключение
```css
@font-face {
  font-family: 'Thousands Letopis';
  src: url('/fonts/ThousandsLetopis[wght].woff2') format('woff2');
  font-weight: 300 700; font-display: swap;
}
h1, .hero-name, .chapter-title { font-family: 'Thousands Letopis', serif; font-weight: 500; }
.all-caps   { text-transform: uppercase; font-feature-settings: 'case', 'cpsp'; }
.counter    { font-variant-numeric: tabular-nums; }
.ancient    { font-feature-settings: 'ss01'; }   /* Λ-образные Л и Д */
```
Для турецкого задавайте `lang="tr"`, иначе `i` в капители будет без точки.
Рекомендуемый кегль - от 18–20 px; для абзацев основного текста нужен отдельный текстовый шрифт со строчными - он в этот пакет не входит.

## Пересборка
```
pip install fontmake ufoLib2 ttfautohint-py opentype-sanitizer
STATIC=1 ./make.sh && python tools/finish.py
```
- `src/glyphs.py` - скелеты букв (линия движения пера), `src/charset.py` - набор и Unicode.
- `src/build.py` - мастера (`MASTERS`: ширина пера, волосная, расширение), засечки (`serif`, `spur`).
- `src/kerning.py` - автокернинг (`DEPTH`, `FACTOR`, `MIN_GAP`).
- `tools/render.py` - пробы: `python tools/render.py dist/variable/…ttf out.png --wght 300,700 "Текст"`.
- `v01/`, `src_v01/` - файлы и исходники прототипа 0.1 для сравнения.

## Проверка в вебе
`webtest/index.html` - автотест для браузера: загрузка VF и статики, покрытие 10 языков без подмены
шрифта, ось веса, kern / tnum / ss01 / cpsp, турецкая i, комбинируемые знаки.
```
python3 -m http.server 8790 -d .   # затем открыть http://localhost:8790/webtest/
```
При обновлении шрифта меняйте версию в URL (`…woff2?v=N`), иначе браузер покажет старый файл из кэша.
