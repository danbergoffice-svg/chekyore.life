# Вертикальный ролик-пролёт (1080×1920, 60 к/с)

Камера одним планом скользит назад вдоль длинной «страницы игры», лежащей на светлом полу студии, и смотрит вверх по ней;
карточки и картинки поднимаются и встают к объективу; в конце камера поднимается, показывает всю страницу полосой,
ныряет в постер, и он становится карточкой под надписью. Озвучка — `vo.mp3` (ElevenLabs, EN, 68,3 с), постер — `poster.webp`.

## Как пересобрать

```bash
npx vite --port 5174                 # из корня проекта, в отдельном окне
node tools/video/flyover/capture-ui.cjs   # снимки экранов игры (сон, итоги, лотерея) → shots/
node tools/video/flyover/capture.cjs      # страница по слоям → layers/ (полосы, элементы, layers.json)
node tools/video/flyover/stills.cjs 0,10,34,61.8 3   # пробные кадры → stills/
node tools/video/flyover/render.cjs 60 3 3           # весь ролик: к/с, подкадров, потоков → out/
```

Рендер без видеокарты (SwiftShader): ~1,3 с на кадр при трёх потоках, весь ролик ~1,5 ч. Кадры складываются
в `frames/60/`, готовые пропускаются — после обрыва просто запустить ещё раз.

## Файлы

- `timeline.js` — общая шкала: скорость камеры, фазы финала, моменты фраз озвучки (по паузам в звуке).
- `landing.html` — страница из настоящих сцен, портретов и экранов игры; заголовок каждого раздела проходит
  середину кадра, когда звучит его фраза.
- `ui.html` — экраны игры (сон, итоги, награды) на английском для `capture-ui.cjs`.
- `film.html` + `film.js` — WebGL2-рендер кадра по времени: `seek(t)`. Наклон камеры 56°, расстояние 1360 → 1700,
  глубина резкости по пикселю (75·(фокус−z)/z перед фокусом, 6·(z−фокус)/z за ним, до 120), тени поднятых элементов
  `#1a2133`, сдвиг (0,1z; 4+0,36z), размытие 7+0,5z, 26 %. Поднятые элементы не заслоняют заголовок над собой,
  пока его читают (`cap`). Финальная надпись — «Летопись» и курсив Alegreya.
- `sfx.py` — вжух на подъёме и нырке, удар при посадке карточки.
- Отступления от исходного промта: размытие движения — 3 подкадра (а не 16) из-за программного рендера.
